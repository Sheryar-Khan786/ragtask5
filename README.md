# RAG Week 5 Assignment - Retrieval-Augmented Generation App

This repository contains a simple RAG pipeline developed for the Week 5 assignment.

## 🔧 Tools Used
- **LLM**: HuggingFace `distilgpt2`
- **Embeddings**: `all-MiniLM-L6-v2`
- **Vector DB**: FAISS
- **Language**: Python (Google Colab)
- **Libraries**: Transformers, FAISS, SentenceTransformers

## 🧠 Features
- PDF/Text dataset upload
- Embedding + FAISS storage
- Chunk retrieval
- LLM response generation based on retrieved chunks
- CLI-based user input
- Sample question: *"What is cybercrime?"*

## 📂 Files
- `rag_pipeline.ipynb` – Code notebook
- `data_source.pdf` – Dataset used
- `report_week5.pdf` – Project Report
- `requirements.txt` – Dependencies
